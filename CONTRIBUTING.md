# Contributing to Jarvis

Fork the repository, create a branch in your fork, and open a pull request against the default branch. Describe the change, the platform you tested on, and how you tested it. Maintainers review pull requests before merging.

Run the tests from the project root with the app dependencies installed.

```bash
python -m unittest discover -s tests
```

Keep API keys, local settings, recordings, and model weights out of commits and issue reports. See LICENSE and THIRD_PARTY.md for licensing and attribution.
